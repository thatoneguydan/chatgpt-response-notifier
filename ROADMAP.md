Preserve **3 silent-stop reloads**, **5 explicit-interruption reloads**, **5-minute surviving explicit retry spacing**, **1 recovery Continue per incident**, and **12 generation-producing actions per trusted human-started run** only as inner incident/run ceilings. They are additionally constrained by the profile-wide traffic governor; new states, reloads and worker restarts do not reset either layer. Completion/resumed work cancels incident-recovery attempts. The separate monitored-chat watchdog is intentionally different: after 30 minutes with no recognized GitHub status code it sends its bounded Continue follow-up even if the request is still generating/unsettled. Passive mode must execute zero automatic reload/Send actions. A page-affecting action still requires fresh conversation/prompt identity and submission-safety inspection immediately before admission.
